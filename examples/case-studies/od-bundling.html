Grid-routed OD bundling

The inter-cell flow network, but each arc is routed through a coarse intermediate grid instead of drawn straight. Arcs travelling the same way snap to the same coarse nodes, so they merge into bundles along shared corridors. Raise the bundling grid to gather more flows onto fewer corridors; lower it toward straight lines.

A cheap grid approximation of edge bundling — no cross-cell state: the coarse routing grid is deterministic screen-space, so shared corridors emerge geometrically. Still analytical bins, not real routes; the network re-forms on pan/zoom. …
