Bristle Map Visualization

About Bristle Maps

Bristle maps project data points to the nearest road segment, aggregate data along each road, and draw bristles perpendicular to the road line.

  • Length: Magnitude/intensity
  • Color: Category/type
  • Orientation: Perpendicular to road
  • Density: Number of bristles
