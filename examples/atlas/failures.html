Cartographic Failure Gallery

The atlas shows what the grammar can express. This shows what the validator catches: every cartographic guardrail in validateSpec, fired by a spec that earns it and then silenced by a spec that repairs it. Where the repair changes the picture, both maps are drawn from the same data so you can see what the warning was actually about.

The warning text on each card is not written here. It is computed as the difference between validating the broken spec and validating the repaired one, so the page cannot claim a repair it did not make.

Each rule encodes a known failure mode of gridded glyphmaps. The technique and its design space are due to Aidan Slingsby (IEEE VIS 2023, doi:10.1109/VIS54172.2023.00009); Screengrid's contribution is making the guardrails machine-checkable. tests/unit/ValidationCoverage.test.js reads the validator's source and fails if any rule loses its worked demonstration.
